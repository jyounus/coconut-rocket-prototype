Adventure mode · world map concepts

Pick a world map for the adventure

Five ways to lay out the same 20 levels, in the spirit of Super Mario World and Donkey Kong Country. Each one is drawn live with the same progress: the first six levels cleared, one branch half-tried, and you standing at the first boss. Every concept forks in the same places, and every one shows where future levels attach. Pick the one you want and copy it back to the chat; then we choose the first level to build.

How the adventure plays

Three stars to move on

reach the finish, hit the coconut target, no revive. The game already tracks these three per stage; the next level unlocks only on all three.

Forks are real choices

At a fork you pick which level comes next. Where branches meet again, the level opens as soon as either branch ends on three stars, so a level you're stuck on never walls you in.

A boss every few levels

Gobblebloom, the Geode King and the Bellows Drake guard the end of each stretch, using the monsters already in the game.

Every level has a best pilot

Each level names the character and ride that suit it, with a real advantage (Bjorn's ice block never freezes in Frost Hollow). It's a reason to unlock more of the shop.

Whichever map you pick, tapping a node opens the same sheet: the three star goals, your best result, and the pilot that suits the level.

If you don't own that pilot, the sheet shows its price and a "Try it once" option (for example after a rewarded ad), so you feel the advantage before you buy it.

The advantage is real but small. Any pilot can still get three stars. The best one just makes it easier.
